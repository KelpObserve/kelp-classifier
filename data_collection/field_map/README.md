# Field observation map

The PNG shows the 90 matched CCMAR quadrat events. The GeoTIFF files contain
EMODnet elevation/bathymetry and the GeoJSON contains OpenStreetMap land geometry.
These are the source assets for the published observation map. Depth source
resolution is about 115 m and does not resolve neighbouring quadrat depths.

The current model-evaluation maps are regenerated by
`training/report_sesimbra_campaigns.py`; they use the campaign predictions.
