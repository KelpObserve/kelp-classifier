# Field observation map

The map shows the 90 matched CCMAR quadrat events: 73 PRESENT and 17 ABSENT.
Campaigns have distinct marker shapes; the labels come from the included
[field observations](../sesimbra_field_observations.csv). This is an observation
map, not a classifier prediction map.

## Reproduce the map

From the repository root, install `requirements-data.txt`, then run:

```sh
python data_collection/field_map/render_map.py
```

The command regenerates `sesimbra_quadrats_observations_map.png` from the included
assets, without network access or model weights. Use `--output runs/field_map.png`
for a separate output. `FIELD_OBSERVATIONS` selects the observation table.
The current renderer replaces the earlier map whose rendering script was not
retained; it preserves the field labels and saved geographic assets.

## Geographic assets and provenance

[assets.json](assets.json) records exact SHA-256 identities and available source
metadata. The figure uses:

- `arrabida_land_osm.geojson`: OpenStreetMap land polygons in longitude/latitude,
  retrieved 14 October 2026. The saved GeoJSON records the API request and
  [OpenStreetMap attribution and ODbL license](https://www.openstreetmap.org/copyright).
- `arrabida_elevation_emodnet.tif`: elevation in metres, negative below sea level,
  on an EPSG:32629 grid. Its raster tags record negation of the earlier
  depth-positive cache on 14 October 2026. The renderer negates elevation to
  display positive depth.
- `emodnet_bathy_arrabida.tif`: retained depth-positive source cache. It is
  provenance evidence; the renderer uses the elevation asset above.

The native depth source resolution is approximately 115 m, resampled to a 10 m
grid. It does not resolve neighbouring quadrat depths. The original EMODnet
product release and exact retrieval request were not recorded: the included
assets reproduce this map, but a new source download cannot be claimed to be
identical. Do not infer source versions from the filenames or resampling date.

The model-evaluation maps are separately regenerated by
`python training/report_sesimbra_campaigns.py`; they use campaign predictions.
